重置提醒：額度一恢復就知道

UsageNow 的每個額度都有即時倒數，並依你所在地區的格式顯示確切的重置時間。除了倒數，你還可以開啟重置提醒，額度一恢復就馬上知道，不必一直回頭去看。

另一邊是用量提醒：選擇 5 小時額度、每週額度或所有額度，再輸入你在意的百分比，例如 90 或 98，想設幾個都可以。每個額度在每個週期只會提醒一次，鎖定畫面也能保持清靜。兩種提醒搭配起來，就是「快用完先通知你，恢復了再通知你」。

至於各服務實際什麼時候重置、額度有多少，由各服務的提供者決定，UsageNow 只負責顯示。這一頁不會替任何服務寫出固定的重置時間點。

多帳號：工作、個人、Pro、Max 一起看

很多人不只一個帳號：公司給一個，自己另外有一個，或是同一個服務同時有 Pro 和 Max。UsageNow 讓這些帳號並排一起看，你可以直接在小工具上翻看你所有的帳號，不必每個帳號各開一次 App。

每個帳號都是在該服務自己的官方登入頁面登入，登入資訊保存在裝置的鑰匙圈中，UsageNow 只與這些服務本身連線。

排序：看哪個帳號最快恢復

帳號一多，順序就很重要。UsageNow 可以依下列方式排序，也能拖移帳號自訂順序：

排序方式適合的情境
5 小時重置時間想知道哪個帳號最快能再用，就切過去繼續做
每週重置時間安排這週剩下的工作量，避免週中被擋下來
用量由高到低先處理快見底的帳號
用量由低到高找出還有餘裕的帳號
名稱或服務帳號很多時，用名稱或服務分類
自訂順序把每天一定要看的帳號拖到最上面

建議在試用的 24 小時內，挑一個正常的工作日實際測試：

  • ☐ 把工作和個人帳號都加進去，確認小工具能翻看每一個帳號。
  • ☐ 放一個主畫面小工具，再放一個鎖定畫面小工具，看看哪個位置你最常瞥到。
  • ☐ 設兩段用量提醒，並開啟重置提醒，看看通知頻率你能不能接受。
  • ☐ 觀察這一天，有沒有因為事先看到額度而調整工作順序。

常見問題

Claude Code 額度什麼時候重置？

由各服務的提供者決定。UsageNow 會顯示每個額度的即時倒數與依你所在地區格式的確切重置時間，並可開啟重置提醒，額度一恢復就通知你。

提醒會不會一直跳出來？

不會。每個額度在每個週期只會提醒一次，鎖定畫面也能保持清靜。你可以自訂想要的百分比，例如 90 或 98，想設幾個都可以。

多個帳號要怎麼排序？

可依 5 小時重置時間、每週重置時間、用量由高到低或由低到高、名稱或服務排序，也能拖移帳號自訂順序。

試用結束後會自動扣款嗎？

UsageNow 沒有訂閱。24 小時免費試用結束後，若要繼續使用 UsageNow 與小工具，是一次性購買解鎖 UsageNow Pro。

購買會不會因為換裝置而失效？

UsageNow 支援 iPhone、iPad 和 Apple Watch。購買如何在你的裝置間共用，由 Apple 依你的 Apple ID 處理，詳情請查看 Apple 的說明。

我的登入資訊存在哪裡？

保存在裝置的鑰匙圈中，UsageNow 只與各服務本身連線。沒有 UsageNow 伺服器，不需要註冊帳號，也沒有任何追蹤。

UsageNow 是一款獨立 App，與 Anthropic、OpenAI、GitHub、Microsoft 及 Google 皆無關聯。Claude、ChatGPT、Codex、GitHub Copilot 與 Gemini 為其各自所有者的商標。各服務有哪些額度、何時重置，完全由該服務的提供者決定；UsageNow 只負責把這些數字顯示出來。
