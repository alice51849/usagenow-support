Codex の使用制限を iPhone で確認する：5時間枠・週間枠と、ほかの AI の上限もひと目で

「Codex の使用制限に当たって作業が止まった」「あとどれくらい使えるのか、いつ戻るのかを先に知りたい」。そう思って検索した人向けのページです。Codex の上限は周期の違う2つの枠で動いていて、しかも Claude や Copilot など別の AI も併用していると、どれがいつ戻るのかが頭の中で追いきれなくなります。ここでは Codex の枠の読み方と、複数の AI の上限を iPhone でひと目で見る方法を紹介します。

Codex の使用制限は「5時間枠」と「週間枠」

UsageNow が表示している ChatGPT Codex の上限は次の2つです。2つの枠は別々に進むので、片方に余裕があっても、もう片方に先に当たることがあります。

枠周期見るポイント
5時間枠短い長いタスクを始める前に、残りとリセットまでの時間を見る
週間枠長い週の前半から使いすぎていないか、残りのペースを見る

UsageNow では、それぞれの枠の残りに加えて、リセットまでのカウントダウンと、正確なリセット時刻をお住まいの地域の表記で表示します。リセットまでの残り時間の見方はリセットまでの残り時間を確認するには？でも Q&A 形式でまとめています。

複数の AI の上限を1画面に並べる

Codex だけを使っているなら、残りを見るのはそれほど大変ではありません。ただ、Claude や Copilot、Gemini も併用していると、「いまどれに余裕があるのか」を確かめるためにいくつもの画面を行き来することになります。UsageNow では次の上限をひとつのアプリで並べて確認できます。

サービスUsageNow が表示する上限
ChatGPT Codex5時間枠と週間枠
Claude5時間のセッション上限と週間上限（モデル別の週間上限も含む）
GitHub Copilotプレミアムリクエスト、チャット、コード補完
Geminiモデルごとの1日あたりのリクエスト上限

仕事用と個人用など複数のアカウントも並べて表示でき、5時間リセットが近い順、週間リセットが近い順、使用量の多い順・少ない順、名前順、サービス順で並べ替えたり、ドラッグして自由な順番にしたりできます。Codex の枠に当たったときに、どのアカウントやサービスに余裕があるかがすぐにわかります。

当たる前にアラートで知らせてもらう

作業に集中しているときは、残りをこまめに見に行くことはまずありません。UsageNow では、5時間の上限、週間上限、またはすべての上限を選び、気になるパーセンテージ（90や98など）を入力してアラートを作れます。アラートはいくつでも追加でき、上限ごと・サイクルごとに1回だけ届くので、ロック画面が通知だらけになることはありません。リセットアラートをオンにすれば、上限が戻った瞬間にわかります。

使用制限に当たったときの動き方

  1. 当たったのが5時間枠か週間枠かを確認する。待つ時間の桁が変わります。
  2. 5時間枠なら、リセットまでのカウントダウンを見て、待つかほかの作業を先に片づけるかを決める。
  3. ほかのアカウントやサービスに余裕があるかを、並べ替えで確認する。
  4. リセットアラートをオンにして、戻ったら通知で知る。

iPhone・iPad・Apple Watch で

ホーム画面とロック画面のウィジェットは全サイズが用意されていて、ウィジェット上ですべてのアカウントをめくって確認できます。Apple Watch のコンプリケーションにも対応しています。

1アカウントの現在の使用量はアプリで確認できます。複数アカウント、使用量アラート、ウィジェット、Apple Watch は1回の購入で使えるようになり、サブスクリプションはありません。

Codex の残りを、ほかの AI と一緒にひと目で。 UsageNow なら、Codex・Claude・Copilot・Gemini の上限とリセットまでのカウントダウンをホーム画面で確認し、使用制限に当たる前にアラートで知らせてもらえます。

よくある質問

Codex の使用制限にはどんな枠がありますか？

UsageNow が表示する ChatGPT Codex の上限は、5時間枠と週間枠の2つです。上限の量やリセットのタイミングを決めるのは OpenAI です。

Codex の残りを iPhone のホーム画面で見られますか？

はい。UsageNow のホーム画面・ロック画面のウィジェットで、5時間枠と週間枠の残り、リセットまでのカウントダウンを確認できます。ウィジェットをタップすると最新の数値に更新されます。

Codex と Claude の上限を同時に見られますか？

はい。Claude の5時間のセッション上限と週間上限、GitHub Copilot のプレミアムリクエスト・チャット・コード補完、Gemini のモデルごとの1日あたりのリクエスト上限も、同じアプリで並べて確認できます。

使用制限に当たる前に知らせてもらえますか？

5時間の上限、週間上限、またはすべての上限を選び、90や98など気になるパーセンテージを入力してアラートを作れます。アラートは上限ごと・サイクルごとに1回だけ届きます。

サインイン情報はどこに保存されますか？

サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。UsageNow のサーバはなく、アカウント登録やトラッキングもありません。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。各サービスにどのような上限があり、いつリセットされるかを決めるのはそれぞれの提供元であり、UsageNowはその数値を表示するだけです。
