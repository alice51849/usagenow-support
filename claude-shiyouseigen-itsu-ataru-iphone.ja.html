Claude の使用制限にいつ当たるかを iPhone で確認する：5時間上限と週間上限の先読み

Claude の使用制限は「2つの時計」で動いている

Claude の使用制限は、ひとつの残量メーターではありません。UsageNow が表示している Claude の上限は次の2種類です。

上限周期当たったときの感覚
5時間のセッション上限短い（5時間の枠）作業の途中で突然止まるが、待てば比較的早く戻る
週間上限（モデル別の週間上限を含む）長い（1週間の枠）週の後半に効いてくる。戻るまで日単位で待つことがある

ポイントは、2つの時計が別々に進んでいることです。5時間の枠がリセットされた直後でも、週間上限の残りが少なければ、そちらに先に当たります。逆に週間上限に余裕があっても、短時間に集中して使えば5時間の枠に当たります。上限の量やリセットのタイミングを決めるのは Anthropic で、UsageNow はその数値を表示するだけです。

いつ当たるかは「残り％」と「リセットまでの時間」で読む

使用制限にいつ当たるかを予想するときに見るのは、残りのパーセンテージと、リセットまでのカウントダウンの2つです。この組み合わせで、次の行動をだいたい決められます。

状況読み方次の行動の目安
残りが多い・リセットまで長いしばらく当たらないそのまま重い作業を始めてよい
残りが少ない・リセットがすぐ当たっても短い待ちで済む長いエージェント実行は数分待ってから始める
残りが少ない・リセットまで長い近いうちに当たり、しばらく戻らない作業を区切る、別のアカウントに切り替える
週間上限の残りが少ない週の後半に止まりやすい重い作業の配分を週の初めから考える

UsageNow は、それぞれの上限についてリセットまでのカウントダウンに加えて、正確なリセット時刻をお住まいの地域の表記で表示します。「あと何分」と「何時何分に戻るか」の両方が見えるので、会議や移動の予定と照らし合わせやすくなります。

当たる前に知らせてもらう：パーセンテージで決めるアラート

使用量を見られるようにしても、集中しているときはまず見ません。そこで、当たりそうなときだけ知らせてもらうのが現実的です。UsageNow では、5時間の上限、週間上限、またはすべての上限を選び、気になるパーセンテージ（90や98など）を入力してアラートを作れます。アラートはいくつでも追加できます。

  • 5時間の上限：作業を区切る合図にする値と、ぎりぎりの値の2つを用意する
  • 週間上限：週の途中で慌てないように、5時間の上限とは別に用意する
  • リセットアラート：オンにすると上限が戻った瞬間にわかり、止まっていた作業をすぐ再開できる

アラートは上限ごと・サイクルごとに1回だけ届くので、ロック画面が通知だらけになることはありません。ウィジェットの置き方など、最初の設定手順はClaude Code の使用量を iPhone で確認する方法にまとめています。

使用制限に当たってしまったときの動き方

  1. まずリセット時刻を確認する。5時間の枠なのか週間上限なのかで、待つ時間の桁が変わります。
  2. 5時間の枠ならリセットまでのカウントダウンを見て、待つか、ほかの作業を先に片づけるかを決めます。
  3. 仕事用と個人用など複数のアカウントがあるなら、5時間リセットが近い順・週間リセットが近い順に並べ替えて、余裕のあるアカウントを探します。
  4. リセットアラートをオンにしておけば、戻った瞬間に通知が届くので、画面を見張っている必要はありません。

複数アカウントの並べ替えや、Codex・Copilot・Gemini との使い分けはClaude・Codex・Copilot の使用量をまとめて管理するアプリで詳しく紹介しています。

iPhone・iPad・Apple Watch で先回りして見る

ホーム画面とロック画面のウィジェットは全サイズが用意されていて、ウィジェット上ですべてのアカウントをめくって確認できます。最新の数値が見たいときはウィジェットをタップすれば更新されます。Apple Watch のコンプリケーションにも対応しているので、会議中でも手首で残りを確認できます。

サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。UsageNow が通信するのは各サービスだけで、UsageNow のサーバやアカウント登録、トラッキングはありません。

料金について：アプリ内で24時間の無料トライアルを開始すると、ウィジェットを含むすべての機能を使えます。その後も使い続けるには1回限りの購入でロックを解除します。サブスクリプションはありません。価格はアプリ内とお住まいの国の App Store で確認できます。

よくある質問

Claude の使用制限にはどんな種類がありますか？

UsageNow が表示する Claude の上限は、5時間のセッション上限と週間上限（モデル別の週間上限を含む）です。上限の量やリセットのタイミングを決めるのは Anthropic です。

使用制限にいつ当たるかを iPhone で確認できますか？

UsageNow のウィジェットで、各上限の残りとリセットまでのカウントダウン、正確なリセット時刻を確認できます。自分で決めたパーセンテージに達したときにアラートを受け取ることもできます。

5時間の枠がリセットされたのに、また止まりました。なぜですか？

週間上限は5時間の枠とは別に進んでいます。週間上限の残りが少ないと、5時間の枠に余裕があってもそちらに先に当たります。UsageNow では両方の残りを並べて確認できます。

上限が戻ったことを知る方法はありますか？

リセットアラートをオンにすると、上限が戻った瞬間に通知が届きます。

Codex や Copilot の使用制限も一緒に見られますか？

はい。ChatGPT Codex の5時間枠と週間枠、GitHub Copilot のプレミアムリクエスト・チャット・コード補完、Gemini のモデルごとの1日あたりのリクエスト上限も表示できます。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。各サービスにどのような上限があり、いつリセットされるかを決めるのはそれぞれの提供元であり、UsageNowはその数値を表示するだけです。
