왜 항상 멈추고 나서야 한도를 알게 될까

클로드의 사용량은 숫자 하나로 관리되지 않습니다. 짧은 주기의 5시간 세션 한도와 긴 주기의 주간 한도가 따로 있고, 주간 한도에는 모델별 주간 한도도 있습니다. 그래서 방금 5시간 한도가 초기화됐다고 안심하고 있다가 주간 한도가 먼저 바닥나는 일이 생깁니다.

게다가 이런 수치는 각 서비스의 설정 화면 깊숙한 곳에 있어서, 터미널이나 에디터에서 작업하는 도중에 일부러 열어 보는 사람은 거의 없습니다. 초기화 시각도 매번 달라서 외워 두기도 어렵습니다. 업무용과 개인용, Pro와 Max처럼 계정을 여러 개 쓰고 있다면 파악은 더 힘들어집니다. 필요한 건 브라우저 탭을 하나 더 여는 게 아니라, 키보드 옆에 놓인 아이폰을 힐끗 보는 것만으로 끝나는 방법입니다.

UsageNow로 아이폰에서 볼 수 있는 사용량

UsageNow는 각 AI 요금제에 남은 사용량과 정확한 초기화 시각을 홈 화면에서 바로 보여 주고, 한도가 바닥나기 전에 미리 알려 주는 앱입니다. Claude뿐 아니라 Codex, Copilot, Gemini도 함께 볼 수 있습니다.

서비스표시되는 내용
Claude5시간 세션 한도와 주간 한도, 모델별 주간 한도까지
ChatGPT Codex5시간 및 주간 사용 구간
GitHub Copilot프리미엄 요청, 채팅, 코드 완성
Gemini모델별 일일 요청 한도

각 한도마다 초기화까지 남은 시간을 실시간으로 카운트다운하고, 정확한 초기화 시각을 사용자 지역 형식으로 표시합니다. 한국 설정이라면 익숙한 날짜와 시간 표기 그대로 읽을 수 있습니다. 홈 화면과 잠금 화면 위젯을 모든 크기로 지원하고, Apple Watch 컴플리케이션도 지원합니다.

아이폰에서 사용량을 확인하도록 설정하는 순서

  1. App Store에서 UsageNow를 내려받아 실행합니다. UsageNow 전용 계정은 따로 만들 필요가 없습니다.
  2. 첫 번째 서비스로 Claude를 추가합니다. 로그인은 Claude 공식 로그인 페이지에서 진행하고, 로그인 정보는 기기의 키체인에 보관됩니다.
  3. 필요하면 Codex, Copilot, Gemini나 업무용·개인용 같은 다른 계정도 추가합니다.
  4. 홈 화면을 길게 누른 뒤 위젯 추가에서 UsageNow를 골라 원하는 크기의 위젯을 놓습니다. 잠금 화면에도 하나 두면 아이폰을 들기만 해도 남은 양이 보입니다.
  5. 알림을 만듭니다. 5시간 한도, 주간 한도 또는 모든 한도를 고른 뒤 신경 쓰이는 퍼센트(예: 90, 98)를 직접 입력하면 됩니다.

위젯에서 바로 모든 계정을 넘겨 볼 수 있고, 최신 수치가 필요할 때는 위젯을 탭하면 새로 고침됩니다. 앱을 열지 않아도 작업 사이사이에 한눈에 상황을 파악할 수 있습니다.

한도에 닿기 전에 미리 알림 받기

사용량이 보이기만 해서는 작업에 몰입해 있을 때 놓치기 쉽습니다. 그래서 알림이 중요합니다. 알림은 원하는 만큼 추가할 수 있으니 다음처럼 단계를 나눠 두는 것을 권합니다.

  • 이른 알림: 5시간 한도에 낮은 퍼센트를 설정해, 지금 하는 작업을 깔끔하게 마무리하라는 신호로 쓰기
  • 직전 알림: 90이나 98처럼 한도에 거의 닿은 값을 설정해, 긴 에이전트 작업을 새로 시작하지 않도록 하기
  • 주간 한도 알림: 5시간 한도는 금방 다시 열리지만 주간 한도는 그렇지 않으니, 주 중반에 당황하지 않도록 따로 알림 두기
  • 초기화 알림: 켜 두면 한도가 다시 열리는 순간 바로 알 수 있어, 멈춘 작업을 곧바로 이어 갈 수 있음

알림은 한도별로 주기마다 한 번만 울리므로 잠금 화면이 조용하게 유지됩니다.

로그인 정보는 어디에 저장될까: 개인정보 보호

유료 요금제 계정을 다루는 앱이라 가장 먼저 궁금해지는 부분일 겁니다. UsageNow의 로그인은 각 서비스의 공식 로그인 페이지에서 진행합니다. 로그인 정보는 기기의 키체인에 보관되며, UsageNow는 각 서비스와만 통신합니다. UsageNow 서버도, 따로 만들 계정도, 추적도 없습니다.

앱은 50개 언어로 완전히 번역되어 있고 한국어도 포함됩니다. 언어는 설정에서 언제든지 바꿀 수 있습니다. iPhone 외에 iPad와 Apple Watch에서도 사용할 수 있습니다.

  • ☐ 남은 양이 적고 초기화가 가까우면 몇 분 기다렸다가 시작하는 편이 중간에 끊기지 않음
  • ☐ 계정이 여러 개라면 5시간 초기화 순으로 정렬해 여유 있는 계정으로 바꾸기
