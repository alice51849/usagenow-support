Claude Code の使用量を iPhone で確認する方法：5時間のセッション上限と週間上限

リファクタリングの途中、エージェントがちょうど調子よく動いているところで「上限に達しました」。Claude Code を毎日使っている人なら一度は経験しているはずです。困るのは上限そのものより、あとどれくらい残っているのか、いつ戻るのかが作業中に見えないことです。このページでは、Claude の使用量の仕組みと、iPhone のホーム画面で残りとリセット時刻を確認する具体的な手順を紹介します。

なぜ上限に気づくのはいつも「止まってから」なのか

Claude の使用量は、ひとつの数字ではなく複数の枠で管理されています。まず短い周期の5時間のセッション上限、そして長い周期の週間上限です。週間上限にはモデル別の週間上限もあります。つまり「さっきリセットされたから大丈夫」と思っていても、週間のほうが先に尽きることがあります。

しかもこうした数値は各サービスの設定画面の奥にあり、ターミナルやエディタで作業している最中にわざわざ開きにいく人はまずいません。リセットされる時刻も毎回ちがうので、覚えておくのは現実的ではありません。仕事用と個人用、Pro と Max のように複数のアカウントを使い分けていると、把握はさらに難しくなります。必要なのはブラウザのタブを増やすことではなく、キーボードの横に置いてある iPhone をちらっと見るだけで済む仕組みです。

UsageNow で iPhone に表示できる使用量

UsageNow は、各AIプランの残りとリセットされる正確な時刻をホーム画面でいつでも確認でき、使い切る前にお知らせもしてくれるアプリです。Claude だけでなく、Codex や Copilot、Gemini もまとめて表示できます。

サービス表示される内容
Claude5時間のセッション上限と週間上限（モデル別の週間上限も含む）
ChatGPT Codex5時間枠と週間枠
GitHub Copilotプレミアムリクエスト、チャット、コード補完
Geminiモデルごとの1日あたりのリクエスト上限

それぞれの上限について、リセットまでのカウントダウンに加えて、正確なリセット時刻をお住まいの地域の表記で表示します。日本の設定なら、見慣れた日付と時刻の書き方でそのまま読めます。ホーム画面とロック画面のウィジェットは全サイズが用意されていて、Apple Watch のコンプリケーションにも対応しています。

iPhone で確認できるようにする手順

  1. App Store から UsageNow をダウンロードして開きます。UsageNow 用のアカウント登録はありません。
  2. 最初のサービスとして Claude を追加します。サインインは Claude 公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。
  3. 必要に応じて Codex、Copilot、Gemini や、仕事用・個人用などの別アカウントも追加します。
  4. ホーム画面を長押しして「ウィジェットを追加」から UsageNow を選び、好きなサイズのウィジェットを置きます。ロック画面にも置いておくと、iPhone を持ち上げるだけで残りが見えます。
  5. アラートを作ります。5時間の上限、週間上限、またはすべての上限を選び、気になるパーセンテージ（90や98など）を入力するだけです。

ウィジェット上ではすべてのアカウントをめくって確認でき、最新の数値が見たいときはウィジェットをタップすれば更新されます。アプリを開かなくても、作業の合間にひと目で状況がわかります。

上限に届く前に知らせてもらう：アラートの使い方

使用量を「見える」ようにするだけでは、集中しているときには見落とします。そこで役に立つのがアラートです。アラートはいくつでも追加できるので、次のような二段構えがおすすめです。

  • 早めのアラート：たとえば5時間の上限で低めの値を設定し、今のタスクをきりのいいところで終わらせる合図にする
  • 直前のアラート：90や98のように上限ぎりぎりの値を設定し、長いエージェント実行を新しく始めないようにする
  • 週間上限のアラート：5時間の枠はすぐ戻りますが、週間上限はそうはいきません。週の途中で慌てないように、週間上限にも別のアラートを用意しておく
  • リセットアラート：オンにすれば上限が戻った瞬間にわかるので、中断した作業をすぐ再開できる

アラートは上限ごと・サイクルごとに1回だけ届くため、ロック画面が通知だらけになることはありません。

サインイン情報はどこに保存される？プライバシーについて

有料プランのアカウントを扱うアプリなので、ここは気になるところだと思います。UsageNow のサインインは各サービス公式のログインページで行います。サインイン情報はデバイスのキーチェーンに保存され、UsageNow が通信するのは各サービスだけです。UsageNow のサーバはなく、アカウント登録もトラッキングも一切ありません。

アプリは50の言語に完全対応しており、日本語ももちろん含まれます。言語は設定からいつでも変更できます。iPhone のほか、iPad と Apple Watch でも使えます。

無料なの？という疑問に正直にお答えします。アプリ内で24時間の無料トライアルを開始すると、ウィジェットを含むすべての機能を使えます。トライアル終了後もUsageNowとウィジェットを使い続けるには、1回限りの購入でUsageNow Proのロックを解除します。サブスクリプションはありません。価格はアプリ内とお住まいの国のApp Storeで確認できます。このページではあえて金額を載せていません。

作業を止めないためのちょっとしたコツ

  • ☐ 長いエージェント実行を始める前に、ウィジェットで5時間の枠の残りとリセットまでのカウントダウンを確認する
  • ☐ 残りが少なく、リセットが近いなら、数分待ってから始めたほうが途中で止まらずに済む
  • ☐ 複数アカウントがあるなら、5時間リセットが近い順に並べて、余裕のあるアカウントに切り替える
  • ☐ 週の後半に重い作業が控えているなら、週間上限の残りを週の初めから意識しておく
  • ☐ 会議中は Apple Watch のコンプリケーションで状況だけ確認する

iPhone でそのまま試すなら UsageNow なら、Claude の5時間のセッション上限と週間上限、さらに Codex・Copilot・Gemini の残りまで、リセットまでのカウントダウンと一緒にホーム画面のウィジェットで確認できます。

よくある質問

Claude Code の使用量は iPhone だけで確認できますか？

UsageNow を使えば、Claude の5時間のセッション上限と週間上限（モデル別の週間上限も含む）の残りとリセット時刻を、iPhone のホーム画面やロック画面のウィジェットで確認できます。

UsageNow のアカウントを作る必要はありますか？

ありません。UsageNow のサーバもアカウント登録もありません。サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。

アラートはどのタイミングで届きますか？

5時間の上限、週間上限、またはすべての上限について、自分で入力したパーセンテージ（90や98など）に達したときに届きます。上限ごと・サイクルごとに1回だけです。リセットアラートをオンにすれば、上限が戻った瞬間にもわかります。

Codex や Copilot の使用制限も一緒に見られますか？

はい。ChatGPT Codex の5時間枠と週間枠、GitHub Copilot のプレミアムリクエスト・チャット・コード補完、Gemini のモデルごとの1日あたりのリクエスト上限も表示できます。

UsageNow は Anthropic の公式アプリですか？

いいえ。UsageNow は独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Google とは提携していません。

無料で使えますか？

アプリ内で24時間の無料トライアルを開始すると、ウィジェットを含むすべての機能を使えます。その後も使い続けるには、1回限りの購入で UsageNow Pro のロックを解除します。サブスクリプションはありません。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。各サービスにどのような上限があり、いつリセットされるかを決めるのはそれぞれの提供元であり、UsageNowはその数値を表示するだけです。
