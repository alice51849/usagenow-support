Claude の使用制限を確認する方法：残りはどこで見て、いつリセットされるのか

「Claude の使用制限、あとどれくらい残っている？」「次に使えるようになるのは何時？」と思って検索した人向けのページです。まず Claude 自身の画面で残りを確認する方法と、5時間の制限・週間の制限がリセットされるタイミングを、Claude ヘルプセンターの記載に沿って整理します。そのうえで、iPhone のホーム画面で残量を見たい人向けに UsageNow でできることを紹介します。

Claude の画面で確認する：設定 > 使用量

Claude ヘルプセンターによると、Pro・Max・Ultra・Team・シートベースの Enterprise プランでは、Claude の「設定 > 使用量」を開くと、5時間のセッション制限と週間制限をどれだけ使ったかが進捗バーで表示されます。なお、ヘルプ記事によっては同じ画面が「設定 > 使用状況」と書かれています。

表示される項目わかること
現在のセッション5時間のセッション制限の使用量と、セッションの残り時間
週間制限すべてのモデル共通の週間制限（プランによっては Fable 用の別枠も）と、次のリセット時刻

「残りはどこで見る？」の答えは、まずここです。ブラウザで claude.ai を開ければ、追加の費用なしですぐに確認できます。

Claude Code で確認する：/usage

ターミナルで Claude Code を使っている場合は、プロンプトで /usage を実行します。Claude Code のドキュメントによると、Pro・Max・Ultra プランの契約者には、同じ画面にプランの使用量バー、アクティビティの統計、使用量の内訳が表示されます。なお、同じ画面の「Session」ブロックに出る金額は API 利用者向けの数値で、サブスクリプションの請求には関係しません。

また、制限に近づくと Claude Code に警告メッセージが表示されます。

5時間の制限と週間制限はいつリセットされる？

制限リセットのタイミング（Claude ヘルプセンターの記載）
5時間のセッション制限最初のメッセージを送ったときに期間が始まり、その5時間後に完全にリセットされる
週間制限アカウントごとに割り当てられた、毎週決まった日時にリセットされる。使い始めた時期やサブスクリプションの開始日では変わらない

つまり5時間の制限は「自分が使い始めた時刻」から数え、週間制限は「アカウントごとに決まった曜日と時刻」で戻ります。正確な時刻は「設定 > 使用量」で確認できます。なお、検証済みの Ultra アカウントには5時間の制限がありません。

確認するときの注意点

  • 使用量は共通：claude.ai、Claude Code、Claude Desktop の使用量は同じ使用制限にカウントされます。ブラウザで使った分も Claude Code の残りに影響します。
  • 2つの制限は別々に進む：5時間の制限がリセットされても、週間制限の残りが少なければそちらに先に当たります。両方の残りを見るのが確実です。
  • 制限の量は変わることがある：Anthropic は容量の管理などのために使用制限を調整することがあると案内しています。

iPhone で残量を見る：UsageNow でできること

「設定 > 使用量」や /usage は、確認したいたびに開く必要があります。作業の合間に iPhone で残量を見たいなら、UsageNow という選択肢があります。

機能内容
Claude の上限5時間のセッション上限と週間上限（モデル別の週間上限も含む）
リセットの表示リセットまでのカウントダウンに加えて、正確なリセット時刻をお住まいの地域の表記で表示
アラート（Pro）5時間の上限、週間上限、またはすべての上限を選び、90や98などのパーセンテージを入力して作成。上限ごと・サイクルごとに1回だけ届く。リセットアラートで上限が戻った瞬間もわかる
ウィジェット（Pro）ホーム画面とロック画面の全サイズ。すべてのアカウントをめくって確認、タップで更新
そのほかChatGPT Codex、GitHub Copilot、Gemini の上限も表示。iPhone・iPad に対応。Apple Watch（コンプリケーション）は Pro

サインインは各サービス公式のログインページで行い、サインイン情報はデバイスのキーチェーンに保存されます。UsageNow が通信するのは各サービスだけで、UsageNow のサーバ、アカウント登録、トラッキングはありません。

無料でできること：無料で見られるのは1アカウントの現在の使用量（アプリ内）です。複数アカウント、使用量アラート、ウィジェット、Apple Watch は、UsageNow Pro を一度購入すると使えます。サブスクリプションはありません。価格はアプリ内とお住まいの国の App Store で確認できます。

Claude の残量を iPhone で見るなら まずは1アカウントの現在の使用量を無料で確かめてみてください。ウィジェットやアラートが必要になったら UsageNow Pro を一度購入すると使えます。

よくある質問

Claude の使用制限の残りはどこで確認できますか？

Claude の「設定 > 使用量」で、5時間のセッション制限と週間制限の使用量、セッションの残り時間、週間制限の次のリセット時刻を確認できます。Claude Code では /usage を実行するとプランの使用量バーが表示されます。

5時間の制限はいつリセットされますか？

Claude ヘルプセンターによると、5時間の期間は最初のメッセージを送ったときに始まり、その5時間後に制限が完全にリセットされます。

週間制限はいつリセットされますか？

週間制限は、アカウントごとに割り当てられた毎週決まった日時にリセットされます。使い始めた時期やサブスクリプションの開始日によって変わることはありません。次のリセット時刻は「設定 > 使用量」で確認できます。

claude.ai と Claude Code の使用量は別々ですか？

いいえ。Claude ヘルプセンターによると、claude.ai、Claude Code、Claude Desktop の使用量は同じ使用制限にカウントされます。

UsageNow は無料で使えますか？

1アカウントの現在の使用量はアプリで無料で見られます。複数アカウント、使用量アラート、ウィジェット、Apple Watch は、UsageNow Pro を一度購入すると使えます。サブスクリプションはありません。

UsageNow は Anthropic の公式アプリですか？

いいえ。UsageNow は独立したアプリで、Anthropic、OpenAI、GitHub、Microsoft、Google とは提携していません。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。各サービスにどのような上限があり、いつリセットされるかを決めるのはそれぞれの提供元であり、UsageNowはその数値を表示するだけです。
