Claude の使用量の見方と確認方法：残り％、リセット時刻、減るペースをつかむ

Claude の使用量は「5時間のセッション上限」と「週間上限（モデル別の週間上限を含む）」の2つの枠で確認します。見るべき数字は、それぞれの枠の残りのパーセンテージと、リセットされる時刻の2つです。このページでは、使用量の数字の読み方、自分の使用量がどれくらいのペースで減るのかのつかみ方、複数アカウントの比べ方を整理し、iPhone のホーム画面でいつでも確認できるようにする方法を紹介します。

Claude の使用量は2つの枠で見る

Claude の使用量は、ひとつの残量メーターではありません。UsageNow が表示する Claude の上限は次の2つです。

枠周期使用量を見るときのポイント
5時間のセッション上限短い（5時間）作業の途中で止まりやすい。リセットまでの時間が短ければ待つ選択もできる
週間上限（モデル別の週間上限を含む）長い（1週間）週の後半に効いてくる。残りが少ないと5時間の枠に余裕があっても止まる

2つの枠は別々に進むので、片方だけを見ていると判断を誤ります。上限の量やリセットのタイミングを決めるのは Anthropic で、UsageNow はその数値を表示するだけです。

使用量の数字の読み方：残り％とリセット時刻

使用量を確認したら、残りのパーセンテージとリセットまでの時間をセットで読みます。

見え方意味次の行動の目安
5時間の枠の残りが多いしばらくは止まらない長いエージェント実行や大きな変更を始めてよい
5時間の枠の残りが少なく、リセットが近い止まっても短い待ちで済む重い作業はリセット後に回す
5時間の枠の残りが少なく、リセットまで長い近いうちに止まり、しばらく戻らない作業を区切るか、別のアカウントに切り替える
週間上限の残りが少ない週の残りの日数に対して余裕がない重い作業を減らし、配分を見直す

UsageNow は各上限について、リセットまでのカウントダウンに加えて、正確なリセット時刻をお住まいの地域の表記で表示します。「あと何分」と「何時何分に戻るか」の両方が見えるので、予定と照らし合わせて判断できます。

自分の使用量が減るペースをつかむ方法

同じ「残り50％」でも、30分で半分使った日と4時間かけて半分使った日では意味が違います。自分のペースを知るには、次のように数日だけ観察するのが手軽です。

  1. 作業を始めるときに、5時間の枠と週間上限の残りをウィジェットで見ておく。
  2. 1時間ほど作業したら、もう一度残りを見て、どれくらい減ったかをメモする。
  3. 長いエージェント実行、短い質問のやり取りなど、作業の種類ごとに減り方を比べる。
  4. 週の初めと週の半ばで週間上限の残りを見比べ、週末まで持つかを考える。

ペースがわかったら、それに合わせてアラートの値を決めます。UsageNow では、5時間の上限、週間上限、またはすべての上限を選び、気になるパーセンテージ（90や98など）を入力するだけでアラートを作れます。アラートはいくつでも追加でき、上限ごと・サイクルごとに1回だけ届きます。リセットアラートをオンにすれば、上限が戻った瞬間にわかります。

複数アカウントの使用量を比べる

仕事用と個人用、Pro と Max のようにアカウントを使い分けているなら、使用量はアカウントごとに比べる必要があります。UsageNow では、すべてのアカウントを並べて表示し、次の順で並べ替えられます。

  • 5時間リセットが近い順・週間リセットが近い順
  • 使用量の多い順・少ない順
  • 名前順・サービス順、またはドラッグで自由な順番

「使用量の少ない順」に並べれば、いま余裕のあるアカウントがすぐわかります。ウィジェット上でもすべてのアカウントをめくって確認できます。Codex・Copilot・Gemini も含めた管理はClaude・Codex・Copilot の使用量をまとめて管理するアプリで紹介しています。

iPhone のホーム画面で Claude の使用量を確認する

  1. App Store から UsageNow をダウンロードして開きます。UsageNow 用のアカウント登録はありません。
  2. Claude を追加し、Claude 公式のログインページでサインインします。サインイン情報はデバイスのキーチェーンに保存されます。
  3. ホーム画面またはロック画面に UsageNow のウィジェットを置きます。ウィジェットは全サイズが用意されています。
  4. 最新の数値が見たいときはウィジェットをタップして更新します。Apple Watch のコンプリケーションでも確認できます。

よくある質問

Claude の使用量はどこで確認できますか？

UsageNow を使えば、Claude の5時間のセッション上限と週間上限（モデル別の週間上限も含む）の残りとリセット時刻を、iPhone のホーム画面やロック画面のウィジェットで確認できます。

使用量の％は「使った量」と「残り」のどちらを見ればいいですか？

判断に使うのは各枠の残りと、リセットまでの時間の組み合わせです。残りが少なくてもリセットが近ければ短い待ちで済みます。

5時間の枠は残っているのに止まるのはなぜですか？

週間上限は5時間の枠とは別に進んでいます。週間上限の残りが少ないと、そちらに先に当たります。

複数アカウントの使用量を比べられますか？

はい。UsageNow では使用量の多い順・少ない順や、5時間・週間リセットが近い順にアカウントを並べ替えられます。

使用量が少なくなったら通知できますか？

5時間の上限、週間上限、またはすべての上限について、自分で入力したパーセンテージに達したときにアラートが届きます。上限ごと・サイクルごとに1回だけです。

UsageNow は Anthropic の公式アプリですか？

いいえ。UsageNow は独立したアプリで、Anthropic、OpenAI、GitHub、Microsoft、Google とは提携していません。

UsageNowは独立したアプリであり、Anthropic、OpenAI、GitHub、Microsoft、Googleとは提携していません。Claude、ChatGPT、Codex、GitHub Copilot、Geminiは各所有者の商標です。各サービスにどのような上限があり、いつリセットされるかを決めるのはそれぞれの提供元であり、UsageNowはその数値を表示するだけです。
